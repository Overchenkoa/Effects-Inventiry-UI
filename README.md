<h1>UI-Отображение действия эффектов в виде таймера</h1>
Небольшой проект в юнити, необходимость в котором появилась в ходе разработки другого проекта. Здесь представлена только часть игорой механики наложения эффектов, а именно - их отображение в UI. Получить информацию о наложении эффекта и его снятии можно с помощью событий в классе EffectStorage.
<h2>Структура папок</h2>
(Начиная с папки Assets)

EffectsUI - Префаб для иконки эффекта. <br>
Effects - Префабы с отдельными эффектами. <br>
Sprites - Спрайты с эффектами (https://craftpix.net/freebies/free-rpg-splash-game-512x512-icons/)<br>
Scripts - Скрипты для проекта <br>
  >Implementation - Скрипт, необходимый для проверки работы системы <br>
  >System - Скрипты, обеспечивающие работу системы

<h2>Скрипты</h2>
<b>Effects</b> - Класс для хранения данных об эффекте. Хранит: название, иконку, максимальную длительность и оставшееся время до снятия эффекта.
<b>EffectUI</b> - Класс для работы с UI-отображением эффектов. Отвечает за ведение и отображение таймера, отображение необходимой иконки, вызов события для EffectStorage при завершении таймера.
<b>EffectStorage</b> - Класс-менеджер для хранения эффектов. Отвечает за создание иконок для эффектов, вызов событий получения и окончания действий эффекта, размещение иконок на экране, их удаление и сортировку при изменении времени действия эффекта.
